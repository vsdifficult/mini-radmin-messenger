# mini-radmin-messenger

P2P-мессенджер для друзей внутри Radmin VPN/LAN на Python + PyQt5.

## Возможности

- Telegram-подобный интерфейс: список чатов, область сообщений, строка ввода, быстрые действия.
- Локальная история SQLite: контакты, чаты, статусы сообщений, вложения-ссылки.
- P2P-текст через TCP внутри Radmin VPN: JSON-сообщения, автопереподключение, typing-события.
- Голосовой UDP-канал через `sounddevice`/`numpy` с управлением запуском из тулбара.
- Поиск по чатам и последним сообщениям.

## Запуск

```bash
pip install PyQt5 sounddevice numpy
python app.py
```

1. Подключите обоих участников к одной сети Radmin VPN.
2. На каждой машине добавьте контакт с Radmin VPN IP второго участника.
3. Откройте чат и отправляйте сообщения. Для текста используется порт `5006`, для голоса — `5005`.

История хранится в `~/.mini-radmin-messenger/db/messenger.sqlite3`.
